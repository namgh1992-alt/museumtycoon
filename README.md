# 뮤지엄 타이쿤

초등학생의 미술 감상 교육을 위해 만든 비영리 미술관 경영 게임이에요.
경매로 명작을 모으고, 미술관을 꾸미고, 도슨트 해설을 들으며 작품을 감상해요.

COPYRIGHT BY 온투

## 주요 기능
- 명작 128점 (회화 106점, 조각·유물 22점), 21개 사조
- 가벽으로 나눈 **전시관**: 같은 사조 작품과 어울리는 벽 테마를 모으면 전시관 보너스
- **쾌적함** 지수: 걸어 다닐 빈 바닥이 넓을수록 점수가 올라가요
- 가운데 줄 끼워 넣기까지 되는 **공간 확장**
- 남성·여성·어린이·어르신·가족 관람객과 배우·평론가·인플루언서 손님 (가벽과 시설을 피해 통로로만 걸어요)
- **1인칭 관람 모드**: 입구에서 출발해 동선을 따라 모든 작품을 감상하고 출구로 나와요 (도슨트 음성 지원)

## 실행 방법
- 설치가 필요 없어요. `index.html` 파일 하나로 실행돼요.
- 인터넷에 연결되어 있어야 3D 엔진(three.js)과 글꼴을 불러올 수 있어요.
- 게임 기록은 브라우저(기기)에만 저장되고, 개인정보는 수집하지 않아요.

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소(Repository)를 만들어요. 예: `museum-tycoon` (Public)
2. 이 폴더의 파일(`index.html`, `README.md`, `.nojekyll`)을 저장소에 올려요.
   - 웹에서: 저장소 첫 화면 → **Add file → Upload files** → 파일을 끌어다 놓고 **Commit changes**
3. 저장소의 **Settings → Pages**로 가요.
4. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `/(root)`로 고르고 **Save**를 눌러요.
5. 1~2분 뒤 `https://<깃허브아이디>.github.io/museum-tycoon/` 주소로 게임이 열려요.

## 이용 시 주의사항
- 교육용 비영리 게임이에요. 수업과 개인 학습에서만 이용해 주세요.
- 작품 이미지는 저작권이 끝난 작품(퍼블릭 도메인)과 국립중앙박물관 공공누리 자료, 메트로폴리탄 미술관 CC0 자료를 썼어요. 자세한 출처는 게임 시작 화면의 「이미지 출처」에서 볼 수 있어요.
- 저작권 보호기간(작가 사후 70년)이 끝나지 않은 작품은 대부분 뺐어요. 이중섭(3점)·잭슨 폴록(3점) 작품은 보호기간이 2026년 12월 31일까지인 작품으로, 교육 목적으로만 담았어요. 조각·유물 일부는 원작을 참고해 새로 만든 3D 모형이에요.
- 교육 외 목적(상업적 이용, 2차 배포, 이미지·모형 추출 등)으로 쓰면 저작권 문제가 생길 수 있어요. 이런 이용으로 생기는 문제의 책임은 이용자에게 있으며, 제작자는 책임지지 않아요.
- 게임 프로그램, 디자인, 직접 만든 3D 모형과 글의 저작권은 온투에 있어요.
